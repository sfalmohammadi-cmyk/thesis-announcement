# إعلان مناقشة خطة بحثية

صفحة لتعبئة إعلان مناقشة خطة بحثية لرسالة ماجستير أو دكتوراه (كلية التربية – قسم المناهج وطرق التدريس) على التصميم المعتمد:

- حقول: نوع الرسالة، الطالب/الطالبة، الاسم، العنوان، اليوم، التاريخ، الوقت، الموجه العلمي، قراء الخطة
- رمز QR يتولد تلقائياً من رابط المناقشة
- معاينة حية مطابقة للتصميم
- حفظ صورة PNG عالية الدقة أو PDF، ومشاركة مباشرة من الجوال
- يعمل بالكامل في المتصفح بدون خادم
